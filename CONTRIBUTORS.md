# Contributors

TrollGram exists thanks to the people and projects below.

## TrollGram

- [vnikolas2009](https://github.com/vnikolas2009): maintainer; privacy
  controls, plugin system (JavaScript and Python), build and signing
  workflows.

Contributions are welcome: see [CONTRIBUTING.md](CONTRIBUTING.md). To be
listed here, add yourself in your first pull request (name or handle, link
and a short note on what you worked on).

## Upstream projects

- [Telegram iOS](https://github.com/TelegramMessenger/Telegram-iOS):
  the application TrollGram is built on.
- [Swiftgram](https://github.com/Swiftgram/Telegram-iOS): features and
  the settings framework.
- [exteraGram](https://github.com/exteraSquad/exteraGram): the Python plugin
  API that the Python host emulates and the model for the JavaScript API.
