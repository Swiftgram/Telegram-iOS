# TrollGram

**Неофициальный клиент Telegram для iOS**

Основан на Telegram iOS и Swiftgram.
Дополнительные функции приватности и система плагинов (JavaScript на встроенном JavaScriptCore и экспериментальный Python).

## О проекте

TrollGram — неофициальный клиент Telegram для iOS, основанный
на исходном коде Telegram iOS.

Проект объединяет отдельные возможности Swiftgram, дополнительные
настройки приватности и систему плагинов: лёгкие JavaScript-плагины без
дополнительных рантаймов и экспериментальные Python-плагины.

Основная цель — предоставить пользователям дополнительные
возможности и сохранить открытость проекта для изменений
и предложений сообщества.

## Возможности

### TrollTweaks

**Настройки → TrollGram → TrollTweaks.** Все переключатели включены по умолчанию
и работают только на стороне клиента.

**Режим призрака** (главный переключатель; остальные действуют только при нём)

- Скрыть статус «в сети», отметки о прочтении, набор текста и статус загрузки.
- Скрыть просмотры историй: истории не помечаются просмотренными.
- Скрыть просмотры постов в каналах.

**Сохранённые сообщения** (журнал только на вашем устройстве, ничего не отправляется)

- Сохранять удалённые: текст, отправитель, время и уже скачанные фото, видео,
  голосовые и файлы входящего сообщения копируются до удаления.
- История правок: текст, который заменила правка.
- Сохранять одноразовые медиа: копия медиа с таймером или одноразового, когда его открывают.
- Одноразовые медиа можно пересматривать: открытие не запускает обратный отсчёт.
- **Журнал сохранённых сообщений**: просмотр записей, копирование текста, очистка
  вместе с сохранёнными файлами.

Удалённые сообщения **не возвращаются** в чат: синхронизация удаляет то, что удалил
сервер, поэтому копия хранится в журнале. Сообщения, которые удалили вы сами, тоже
попадают в журнал, пока вы его не очистите. Файлы сохраняются, только если были скачаны.

**Контент:** удаление рекламных сообщений и работа с защищённым контентом.

Функции не гарантируют полной анонимности или защиты от серверов Telegram, а на других
устройствах чат может оставаться непрочитанным при скрытых отметках о прочтении.
Сохранение того, что отправили или удалили другие, может нарушать их ожидания и закон
вашей страны: используйте ответственно.

### JavaScript-плагины

JavaScript-плагины выполняются на JavaScriptCore, который уже есть в iOS:
без встроенного интерпретатора и тяжёлых нативных мостов. Каждый плагин
работает в собственном изолированном контексте.

- Импорт файлов `.js` из «Файлов» (**Настройки → Plugins**).
- Плагины **выключены, пока вы их не включите**.
- Плагин может описать экран настроек (переключатели, поля ввода, кнопки),
  который приложение рисует нативно.
- Команды в чате: исходящие сообщения вида `.команда аргументы`.
- Доступ к Telegram: `TrollGram.sendMessage`, `TrollGram.getPeer`,
  `TrollGram.api(method, params)`, **Bot API** через `TrollGram.bot(token)`
  и `fetch` на Promise.

Полное описание API: [`Swiftgram/JSPlugins/README.md`](../Swiftgram/JSPlugins/README.md),
примеры: `Swiftgram/JSPlugins/examples`. Тесты (Node.js 18+):
`node --test Swiftgram/JSPlugins/tests/prelude.test.js`.

### Python-плагины

В приложении реализована экспериментальная поддержка Python 3.11.

Доступные возможности:

- Импорт файлов `.plugin` (exteraGram) и `.py`: плагины exteraGram — это обычный
  Python-код, они запускаются как есть.
- Экран настроек плагина (`Header`, `Switch`, `Input`, `EditText`, `Selector`, `Text`)
  рисуется нативно в меню плагинов.
- Как писать плагины: [`Swiftgram/PythonPlugins/README.md`](../Swiftgram/PythonPlugins/README.md).
- Включение и отключение отдельных плагинов.
- Просмотр журналов работы.
- Отдельное хранение данных плагинов.

Стандартные директории:

| Назначение | Путь |
| --- | --- |
| Плагины | `Documents/Plugins` |
| Данные плагинов | `Documents/PluginsData` |

Устанавливайте плагины только из проверенных источников.
Python-код выполняется внутри среды приложения и может получать
доступ к доступным ему данным.

### Совместимость

В проект включены отдельные функции и компоненты совместимости
из exteraGram.

Не все возможности других Telegram-клиентов доступны в TrollGram.

## Установка

Рекомендуемый способ установки — IPA-файлы из раздела
[GitHub Releases](../../releases).

Способ установки зависит от метода подписи и версии iOS.

## Сборка проекта

### Требования

- macOS
- Xcode
- Python 3
- Git
- Инициализированные Git submodules

### Клонирование

```bash
git clone --recursive https://github.com/vnikolas2009/TrollGram.git
cd TrollGram
git submodule update --init --recursive
```

### Подготовка окружения

```bash
python3 build-system/setup_python.py
```

### Сборка

```bash
python3 build-system/Make/Make.py \
  --cacheDir="$HOME/bazel-cache" \
  --bazelUserRoot="$HOME/bazel-trollgram" \
  build \
  --configurationPath=build-system/appstore-configuration.json \
  --codesigningInformationPath=build-system/fake-codesigning \
  --configuration=release_arm64 \
  --buildNumber=1000 \
  --skipDsym \
  --overrideXcodeVersion
```

В зависимости от окружения параметры сборки могут потребовать изменений.

## Сборка через GitHub Actions

Workflow `.github/workflows/build-ipa.yml` собирает IPA. Для входа в аккаунт
нужны секреты `TG_API_ID` и `TG_API_HASH` (приложение с my.telegram.org/apps,
платформа «other»); для подписи — `P12_BASE64`, `P12_PASSWORD` и
`MOBILEPROVISION_BASE64`. Полная таблица и команды: [SECRETS.md](SECRETS.md).
Не публикуйте значения секретов в репозитории и не присылайте их в чат.

| `Swiftgram/SGTrollPrivacy` | Ключи, значения по умолчанию и группы TrollTweaks |
